Add a queued job App\Jobs\ChargeOrder that charges an order through App\Services\PaymentGateway, and dispatch it from App\Services\OrderPlacement::place() for the order it creates. Its constructor takes the order id as a public property: new ChargeOrder(int $orderId), read back as $job->orderId. Requirements: an order must never be charged twice, even if the job is retried, redelivered or dispatched twice for the same order. Never charge for an order whose transaction rolled back; if the order no longer exists when the job runs, finish without charging and without failing the job. On success set the order's status to paid and store the charge id in charge_id. A declined card (PaymentDeclined) is final: set the status to payment_failed and don't retry. A gateway outage (GatewayUnavailable) must be retried with increasing delays for up to an hour.
